//06 — How It Works

Three steps.
One living memory.

Step 01
Extract

Click the MerOb button in any ChatGPT, Claude, or Gemini chat. The extension captures the full conversation.

Step 02
Process Locally

Topics, entities, and wikilinks are extracted on your machine. Plain Markdown notes land directly in your Obsidian vault.

Step 03
Recall

A floating panel surfaces relevant memories as you type in any AI chat. Inject past context with one click.

//08 — Capabilities

Everything you need.
Nothing you don't.

One-click Capture

Extract full conversation threads from ChatGPT, Claude, and Gemini with a single browser action.

Auto Knowledge Graph

Topics and entities are linked automatically, forming a browsable network of everything you've explored.

Plain Markdown Output

Every note is a standard .md file — readable anywhere, portable forever, never locked in a proprietary format.

100% Offline Processing

Zero network calls for extraction or linking. Your data never leaves your machine. Privacy by architecture.

Floating Recall Panel

A non-intrusive overlay surfaces relevant memories while you type — inject them with one click.

Cross-Platform Memory

Insights from a Claude session appear when you open ChatGPT. One unified memory layer across all your AIs.

//10 — Get Started

Up and running
in 3 steps.

No account, no cloud. Just clone, run, and start capturing.

1
Clone & install
git clone https://github.com/nicobailon/merob && cd merob
2
Start the local server
./start.sh  # or start.bat on Windows
3
Load the Chrome extension
# chrome://extensions → Enable Developer Mode # → Load unpacked → select /merob/chrome_extension
