# Recording the demo GIF

The GIF at the top of the README is the single most important asset for stars.
Most people decide to star **from the GIF**, before reading a word. Keep it under
~20 seconds, no audio, large text.

## Tools
- macOS: [Kap](https://getkap.co/) (free) → export as GIF
- Windows/Linux: [ScreenToGif](https://www.screentogif.com/) (free)
- Keep the capture window small (e.g. 1200×750) so the GIF stays light (< 5 MB).

## Storyboard (target ~20s)

| Time | Shot | What the viewer sees |
| ---- | ---- | -------------------- |
| 0–3s | A real ChatGPT/Claude conversation on screen | "this is just a normal AI chat" |
| 3–5s | Cursor clicks the **⬆ Extract** button in the 🧠 panel | the one action |
| 5–7s | Quick toast / "Memories extracted ✅" | it did something |
| 7–8s | **Hard cut** to Obsidian | context switch |
| 8–14s | Obsidian **Graph View**: 2–3 new nodes pop in and link to existing ones | the payoff — the brain grows |
| 14–18s | Hover/click one new memory note → show the clean Markdown + `[[wikilinks]]` | "it's plain files I own" |
| 18–20s | Zoom out on the full graph | the dream: a second brain |

## Tips
- Pre-stage a vault with ~30 notes so the graph already looks alive.
- Do the extract on a short, real conversation so new nodes clearly appear.
- Add a 1-line caption burned into the GIF: *"Your AI chats → an Obsidian graph, automatically."*
- Export, drop the file at `docs/demo.gif`, commit. The README already points to it.
