# Architecture mémoire - AI OS

## Objectif

AI OS doit transformer les conversations IA en mémoire structurée, validée et réutilisable.

Le système ne doit pas seulement stocker des informations. Il doit maintenir une base de connaissances propre, cohérente et utile dans le temps.
